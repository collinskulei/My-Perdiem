# **App Name**: PerdiemPro

## Core Features:

- Registration Wizard: Guide new users through registration, capturing personal and employment details.
- Admin Dashboard: Provide a dashboard for admins to view registered employees, track check-ins, perdiem requests, and download request data.
- Check-in & Request Wizard: Enable employees to log in, check-in at event locations, and start a perdiem request wizard.
- Location Validation: Use device GPS to confirm the employee is within a 1 km radius of the event location before they can submit their perdiem request.
- Automated Perdiem Calculation: Automatically calculate the total perdiem amount based on activity information, transport information, and location.
- Data Completeness Checker: Use AI to make sure the required data fields have been completed. The tool double-checks if fields left incomplete appear relevant given the other information provided in the request. The LLM is instructed to generate only 'complete' or 'incomplete'.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke trust and professionalism, drawing from the reliability required in financial management.
- Background color: Very light blue (#E8EAF6) to provide a calm and clean backdrop, in line with a light scheme.
- Accent color: Vibrant purple (#9C27B0) to highlight important actions and data points, ensuring they stand out without overwhelming the user.
- Font: 'Inter', a grotesque-style sans-serif, will be used for both headlines and body text, conveying a modern and neutral appearance, appropriate for all text.
- Use clear and simple icons that represent each perdiem request and action for easy recognition.
- Maintain a clean, intuitive layout with a focus on prioritizing key information and actions.
- Use subtle animations for feedback on interactions such as successful check-in or perdiem submission.
